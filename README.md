# Fast Quote for MyBB

This plugin provides a very fast quote option - select text and click the button!

Quote has never been so easy!

Additional fast quote button provides a super-fast option to quote selected text.
It supports whole post (just click it), or only selected area.
It also supports mycode/bbcode in quoted posts.

Admin can set button CSS style in plugin settings.
Form name, field name and alt/title text can be also set.

## Compatibility

Version 2.x targets current MyBB 1.8.x releases and PHP 8.x.

It keeps the existing setting names for easier upgrades, but replaces the legacy JavaScript with a modern MyBB-oriented implementation and removes inline JavaScript from the quote button template.
